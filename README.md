# Hoba Light

All code was generated by ChatGPT 6.1 Sol.
It has not yet been reviewed by a human.

A command-line backup tool for Linux, Windows, and macOS.
Use `hobalight` or the shorter `hl`.

[Install](docs/installation.md), then back up a directory:

```sh
hl /path/to/documents
hl browse
```

Backups are not encrypted.
